# Methodology
Business problem → data quality checks → SQL preparation → exploratory analysis → statistical testing → logistic regression → model evaluation → cohort retention → Power BI → business recommendations.

Categorical relationships: Chi-square + Cramer's V.
Numeric group differences: Welch's t-test + Cohen's d.
Predictive model: Logistic Regression with stratified train/test split.
Evaluation: Accuracy, Precision, Recall, F1 and ROC-AUC.

Statistical association does not establish causation.
